# Russian Cultural Code Dataset

Структурированные данные для обучения искусственного интеллекта пониманию русского культурного кода.

## 🎯 Цель проекта
Решить проблему культурной нерелевантности ИИ при работе с русскоязычными запросами. Создать инфраструктуру данных для тонкой настройки языковых и генеративных моделей.

## 📁 Что внутри
- Онтологии культурных концептов (космонавт, тоска, авось и др.)
- Промпты и эталонные ответы для обучения
- Визуальные референсы для генерации изображений
- Метрики оценки культурного соответствия

## 🚀 Быстрый старт
Первым концептом стал ["космонавт"](cosmonaut_ontology.json) — разбор визуальных и смысловых отличий русского и американского подходов к космосу.
